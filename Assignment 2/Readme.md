# Assignment 2 - E-commerce Site (Static, Responsive)
## Reference Site
-	**Name:** Dawlance Pakistan
-	**URL:** https://www.dawlance.com.pk/- **Screenshot:** ![Reference site](reference.png)  <!-- save your screenshot of the Dawlance homepage as       reference.png in this folder -->
## Files
-	`index.html` - homepage: navbar with logo and cart icon, banner, grid of 8 product cards, footer- `product.html` - product detail page: larger image, name, price, description, quantity box, Add to Cart button,       same navbar and footer - `Style.css` - my own CSS (sticky footer and footer columns with Flexbox)
-	Bootstrap 5 (CDN) is used for the navbar and the grid (`row`, `col`, `row-cols-*`)
## Responsive behaviour
-	Phone (~375px): hamburger menu, 1 product per row
-	Tablet (~768px): full navbar, 2 products per row
-	Desktop (992px and above): 4 products per row
